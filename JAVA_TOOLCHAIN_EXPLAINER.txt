How Java 25 runs in this environment despite JAVA_HOME being Java 21:

The system's default java on PATH is Java 21 (Temurin 21.0.7). However, JDK 25
(Eclipse Adoptium 25.0.3.9) is also installed at:
  C:\Program Files\Eclipse Adoptium\jdk-25.0.3.9-hotspot\

The build uses Gradle's Java Toolchain feature, configured in build.gradle.kts:

    java {
        toolchain {
            languageVersion.set(JavaLanguageVersion.of(libs.versions.jdk.get().toInt()))
        }
    }

The version is pulled from gradle/libs.versions.toml:

    jdk = "25"

Gradle's toolchain auto-provisioning detects JDK 25 is already installed locally
and uses it to compile and run the game, regardless of the system JAVA_HOME.
That's why the crash reports show "Java Version: 25.0.3" even though the shell's
"java -version" returns 21.

The system JDK 21 is only used to run Gradle itself. The game client
(./gradlew runClient) launches with JDK 25 via the toolchain.
