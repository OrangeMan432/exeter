# 5b5t profile

Preset: `config-presets/5b5t.json`. Drop it into
`<minecraft>/earthhack/modules/` (same folder the client saves
configs to) and load it from the Configs GUI. Unknown entries are
skipped by the loader, so a partial preset is safe.

## What it turns on

Dupe core: AutoItemDupe (confirmed, HELD mode, auto-repeat).
Intel: StashFinder, NewChunks, TPCoordLog, PopNotify, PearlNotify,
VisualRange, GlobalLocation thunder, GhastNotifier, Tracker.
Survival: AutoMend, ArmorWarner, FastExp off by default (enable for
mending sessions), AntiVoid, AutoEat, AutoRespawn, AutoArmor,
AutoTool, AutoMount, BoatFly off by default, NoAFK, MCF, NoKick
slime guard.

## Dupe runs

AutoItemDupe: keep oak planks anywhere in inventory, hold the item,
toggle on, wait for pickup. If the count fails to rise, open the
recipe book manually and try again.

AutoShulkerDupe (enable per run, Confirm already true): stand on a
crafting table flush with the ground, look straight down, shulker
in hand, diamond pickaxe in hotbar, planks in inventory.

## Prism 1.12.2 checklist for the human

1. Fresh Prism instance, Forge 1.12.2-14.23.5.2768, Java 8.
2. Exeter jar + Baritone Forge jar in mods (Baritone optional,
   needed for GhastFarmer and `+baritone` commands).
3. Join, open ClickGui, bind movement and combat keys.
4. Copy the preset as above, load it, verify modules toggle.
5. Report back: anything that errors, desyncs, or flags.
